1. Global Application Lifecycle & Route Resolution

Every incoming HTTP request first passes through the Root Shell (app/layout.tsx). Next.js evaluates the requested path and mounts the matching route component inside <main id="main-content"> while keeping the Navbar, Theme Provider, and Footer persistent.

How Dynamic Project SSG Works (/projects/[slug]) 1. generateStaticParams() reads all project slugs from utils/projects.ts and builds static HTML for each at build time.
2. dynamicParams = false ensures invalid slugs immediately return the 404 page.
3. generateMetadata() automatically sets the document title (e.g., "Klar | Abdul Rahman") and OpenGraph tags.
4. Features list with custom SVG checkmarks and Tech Stack Badges rendered using components/Badge.tsx.
How Projects & Blog Catalogs Work (/projects & /blog) 1. app/projects/page.tsx loads all projects and feeds them into components/ProjectGrid.tsx.
2. app/blog/page.tsx iterates over utils/blog.ts to render BlogCard.tsx components.
3. Each blog card uses formatDate() from utils/helpers.ts to format UTC publication dates and links directly to Hashnode.

5. Content Maintenance Cheatsheet

Reference guide for editing content without touching JSX layout structures:

Personal Details & Social Links Edit utils/site.ts → Update your name, handle, job title, email, or social profile URLs.
Skills & Tech Stack Edit utils/profile.ts → Append tools to the skills categories array.
Work Experience & Education Edit utils/profile.ts → Update the internship or education items.
Add / Edit Projects Edit utils/projects.ts → Modifying an entry updates both /projects and /projects/[slug].
Publish New Articles Edit utils/blog.ts → Adding a post updates both the landing page and /blog.
Color Palette & Design Tokens Edit app/globals.css → Update CSS custom properties under :root and .dark.
