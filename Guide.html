/sitemap.xml app/sitemap.ts Dynamic XML Auto-indexed URL sitemap for search engine crawlers
/robots.txt app/robots.ts Dynamic Text Crawler indexing directives

5. Content Maintenance Cheatsheet

Reference table for updating portfolio content without touching UI templates:

Personal Details & Social Links Edit utils/site.ts → Update name, handle, job title, email, or social URLs.
Skills & Tech Stack Edit utils/profile.ts → Append tools to the skills categories array.
Work Experience & Education Edit utils/profile.ts → Update internship or education items.
Add / Update Projects Edit utils/projects.ts → Modify title, description, features list, or demo URLs.
Publish New Articles Edit utils/blog.ts → Add article title, description, publication date, and Hashnode URL.
Color Palette & Design Tokens Edit app/globals.css → Update CSS custom properties under :root and .dark.
